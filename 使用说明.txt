UC 多线程下载器 — 使用说明
================================

更新日志（本版）
----------------
1. 去掉了繁琐的 F12 操作。
2. 直接粘贴分享链接即可，不用改什么 fast 了，自带了。
3. 新增了选择下载位置。
4. 不登录也能下，速度比较慢。
5. 选择登录会弹出网页登录，自行登录即可，cookie 会保存，下次使用会复用；
   如果失效会提示。建议还是登录使用，下得快一点。
6. 新增「粘贴二维码」：从剪贴板读二维码；带提取码自动填入并开始，只有链接也直接开始，
   UC 提示需要提取码时弹窗输入。
7. 下载改成多任务列表：每项显示文件名和进度，可单独暂停/继续/移除；继续不用重新粘链接。


作用
----
UC 网页下载是按“单个连接”限速的（游客约 100KB/s，登录约 500KB/s）。
本工具把文件切成块、同时开几十条连接拉取，实测登录态 64 连接能到 20~30MB/s，
并支持断点续传、自动重试、大小与空洞校验。


使用方法
--------
1) 直接把分享链接粘进去；如果有提取码，提取码也粘进去。
2) 不登录也可以下载，速度较慢；登录之后可以更快地下载。
3) 二维码也行：先把二维码复制成图片，点「粘贴二维码」。
   带提取码会自动填入并开始；只有链接也直接开始，需要提取码时会弹窗。


二维码
------
拿到的是二维码图片时：
  1) 先把二维码复制成图片（截图、微信/QQ 复制图片、资源管理器复制图片文件都行）
  2) 点「粘贴二维码」
  3) 程序自动识别链接和提取码，填入并开始下载

支持的二维码内容：
  · 只有链接（直接开始，需要提取码时弹窗）
  · 链接 + 提取码
  · 链接 + 提取码 + 说明文字


多任务列表
----------
每加一个链接或二维码，「下载列表」里就多一行：
  · 第一行是文件名，下面显示进度、已下载/总大小、速度和剩余时间
  · ⏸ 暂停：停止当前连接，已完成的块和进度会保存
  · ▶ 继续：自动重新取直链，从断点续传，不需要重新粘链接
  · ✕ 移除：只从列表移除，已下载的文件和未完成的临时文件都保留
多个任务会同时下载、共享带宽；任务多时可以把每个任务的连接数调低一点。


登录与保存位置
--------------
· 登录：点「登录（手机号/验证码）」，弹出的浏览器窗口里自行登录即可。
  cookie 会自动保存，下次使用复用；如果失效会提示。建议登录使用，下得快一点。
· 保存位置：默认是 用户目录\Downloads；点「浏览…」可以自己选，选过会记住；
  点「默认」恢复默认位置。


背后做了什么（技术说明）
------------------------
UC 分享页背后是三个接口，全程不需要手填 Cookie：
  POST pc-api.uc.cn/1/clouddrive/share/sharepage/token   {pwd_id, passcode} → stoken
  GET  .../share/sharepage/detail?pwd_id=&stoken=...                    → 文件列表
  POST .../1/clouddrive/file/download  {fids, pwd_id, stoken, fids_token} → 签名直链

直链是阿里云 OSS 签名地址，额外带 callback 鉴权；OSS 会拿请求里的
Cookie / Referer 回调 UC 校验，所以请求必须带上同一会话的 Cookie。

直链里 callback-var 的 x:token 能看出身份：
  游客 ...-5-7-100-...   单连接约 100KB/s
  登录 ...-2-7-500-...   单连接约 500KB/s
工具会在日志里直接告诉你这次是「游客态」还是「登录态」。

直链有效期约 3 小时，每次点开始都会重新取，不用担心。


参数说明
--------
· 连接数：游客默认 128（实测 64→6.2、128→10~11、192→12.6、256 反而下降）
          登录默认 64（每连接 500KB/s，64 条就能吃满大多数家宽）
· 分块：游客默认 1MB，登录默认 4MB
        网络抖动大可以降到 1~2MB；分块越大，中途停止时丢弃的在途数据越多


断点续传
--------
· 进度保存在同名文件的 .parts.json 里，每完成一块就写一次
· 中途停止/关窗/崩溃，下次重新粘分享链接点开始即可续传
· 分块收完才写盘，最坏只是重下几个分块
· 完成后自动校验文件大小 + 全零块扫描


常见问题
--------
· 提示「需要提取码」/「提取码不对」
  → 填进「提取码(可空)」再点开始。提取码不区分大小写。

· 登录窗口没弹出来
  → 需要本机有 Chrome 或 Edge；看任务栏是不是被挡住了。

· 登录了还是显示游客
  → 看日志里的「直链是游客态/登录态」。如果是游客态，点「清除」再登一次。

· 解析一直不动 / 卡在「正在解析」
  → 日志会显示当前步骤；点「停止」会立刻取消解析（不会卡界面）。
    反复失败可以诊断：UC下载器.exe --resolve-test "分享链接" 提取码
    结果在 %LOCALAPPDATA%\UC下载器\resolve_test.txt，报错堆栈在同目录 error.log

· 报 403 require login [auth not found]
  → 直链过期或登录态失效。分享链接模式再点一次开始即可（会自动重取直链）；
    现在是分享链接模式，再点一次「开始」即可。

· 进度条开头几秒增幅偏小
  → 正常，按“已接收字节”统计，建连时偏低。

· 杀毒软件报警 / 提示未知发布者
  → 这类单文件小工具常被误报。不放心可以直接跑源码 python uc_gui.py。

· 打不开、闪退
  → 同目录会生成 crash.log，把内容发回来即可定位。


文件说明
--------
· UC下载器.exe     本地打包产物（不入库；源码直接跑 uc_gui.py）
· UC下载器_old.exe 旧版本地备份（不入库）
· uc_gui.py   图形界面
· uc_api.py   分享解析 / 浏览器登录态抓取 / Cookie 加密存储（标准库）
· download.py 命令行版（读同目录 url.txt / cookie.txt）

登录态存储位置：
  %LOCALAPPDATA%\UC下载器\login.dat（Windows DPAPI 加密，只有当前用户能解）


已知限制
--------
· 目前一次下一个文件；文件夹分享会提示暂不支持
· 依赖 UC 现有的分享接口，UC 改规则时可能需要更新
· 登录需要手机号+验证码；程序不做验证码识别，滑块和短信都在网页里完成
